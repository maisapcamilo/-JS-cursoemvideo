Fatorial

O fatorial de um número inteiro é dado pela multiplicação do mesmo pelos seus antecessores até chegar ao elemento neutro da multiplicação o número 1. O fatorial é representado pelo símblo '!' de exclamação. A expressão genérica que define o fatorial de um número inteiro (n) é n! = n.(n-1).(n-2).(n-3)....2.1.

Exemplos:

4! = 4 x 3 x 2 x 1 = 24

5! = 5 x 4 x 3 x 2 x 1 = 120

7! = 7 x 6 x 5 x 4 x 3 x 2 x 1 = 5040
